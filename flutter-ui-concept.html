Sistema visual

Outdoor técnico, no interfaz genérica.

Verde bosque para infraestructura estable, naranja para acción y atención, azul para rutas indirectas y crema para legibilidad. Las líneas y etiquetas expresan semántica; el color nunca es la única señal.

01
La red es la pantalla principal

No se oculta en settings. El laboratorio existe para ver conexiones, rutas, aislamiento y recuperación.

02
Conexión y reachability no se mezclan

Directo, vía mesh y miembro sin ruta tienen formas, líneas, textos y conteos diferentes.

03
PTT domina cuando se usa

Botón grande, máximo de ocho segundos, feedback háptico y entrega durable comprensible.

04
Ingeniería sin debugger

Scores, ETA, custody, chunks y failover aparecen en una vista especializada y redacted.

05
Adecuada para dashboard

Targets grandes y lectura breve en modo normal; el detalle técnico se usa detenido o por un pasajero.

Usa las cuatro pestañas del teléfono para recorrer el concepto.

Estados clave

Un lenguaje visual consistente.

Estas piezas se convierten en componentes Flutter reutilizables. Cada una necesita estado semántico, variante compacta y representación accesible en lista.

CONNECTIVITY

Directo y autenticado

Línea sólida, transporte activo y calidad estable. No se usa únicamente un punto verde.

REACHABILITY

Alcanzable vía mesh

Ruta segmentada con next-hop y número de saltos; nunca parece una conexión física.

YO ┄ MARÍA ┄ LUIS
LINK QUALITY

Tendencia, no metros

Calidad categórica y métricas opcionales. RSSI aislado no se convierte en distancia.

SECURITY

Confianza verificable

Miembro, epoch y autenticación; fingerprint disponible sin exponer claves o IDs del radio.
